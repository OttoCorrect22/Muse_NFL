Quick glossary

EPA = expected points added — how much each play helps a team score, on average. Think of it as a per-play report card.

Win probability = how the predicted score gap converts to a chance of winning (a bigger predicted gap = a higher chance).

What the model sees

  • Team stats through Tuesday morning of game week
  • Only games from earlier weeks — never the same week
  • The starting QB from last week's actual game (injury news almost never breaks before Tuesday)

What the model never sees

  • Betting lines or odds — of any kind, at any time
  • The closing line is only a benchmark on the Scoreboard, so we can grade ourselves against Vegas
